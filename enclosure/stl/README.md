# enclosure/stl/

Berkas **mesh siap-cetak (STL)** hasil ekspor Fusion 360, dipakai untuk slicing di Bambu Studio (Bambu Lab P1S).

| Berkas | Fungsi |
| --- | --- |
| `Top_Frame.stl` | Bingkai depan penahan cermin two-way + panel |
| `base_enclosure1.stl` | Casing bawah bagian 1 |
| `base_enclosure2.stl` | Casing bawah bagian 2 |

> Letakkan ketiga berkas STL di folder ini. Sumber CAD editable (`.f3d`, `.step`) disimpan di `../cad/`. Parameter cetak & alur konversi ada di `../print-settings.md`. Berkas 3MF hasil slice disimpan di `../print/` (buat bila sudah ada).
